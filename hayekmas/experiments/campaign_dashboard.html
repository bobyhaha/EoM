Fixed-answer grading reliability

Post hoc check: three new grades of every submitted primary answer using the same saved judge prompt. Primary scores remain unchanged. Missing submissions retain zero; a mean is shown only when all submitted answers have valid grades. This measures grading variation, not independent scientific validation. The allowance is $0.50 per system inside the existing caps.
